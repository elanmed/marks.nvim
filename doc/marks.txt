`MARKS.NVIM`                                                *marks-marks.nvim*


A set of utilities to smooth out native vim marks.


------------------------------------------------------------------------------
SAMPLE CONFIGURATION                              *marks-sample-configuration*


>lua
    vim.g.marks = {
      -- defaults:
      notify = true,
      highlighted_char_set = marks.local_marks .. marks.global_marks,
    }
    
    local marks = require "marks"
    marks.setup {
      -- defaults:
      remap_m = true,
    }
<
